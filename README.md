# carlosferreyra/.github

Default community health files and contribution templates for public
repositories owned by [@carlosferreyra](https://github.com/carlosferreyra).

GitHub uses this public, specially named repository as a fallback when another
repository under the same account does not define its own policy or template.
The defaults include contribution and security policies, issue and pull request
templates, discussion category forms, and funding configuration.

## Documentation

Start with the [practical guide](./docs/index.md) to learn:

- which files GitHub inherits and how override precedence works;
- how to use and customize each community health file;
- how issue, pull request, and discussion templates behave;
- which settings must still be configured per repository;
- how to publish the guide from `docs/` with GitHub Pages.

## Repository structure

- [`.github/`](./.github/) contains the inherited defaults.
- [`docs/`](./docs/) contains the GitHub Pages documentation source.
- [`LICENSE`](./LICENSE) licenses this template repository; licenses are not
  inherited by other repositories.

Detailed guidance belongs in `docs/`; this README is intentionally an entry
point rather than a second copy of the documentation.
